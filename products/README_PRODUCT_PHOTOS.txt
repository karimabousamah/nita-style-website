Put your original high-quality product photos in this folder before deploying to Netlify.

Example:
assets/products/red-bag-1.jpg
assets/products/red-bag-2.jpg
assets/products/red-bag-3.jpg

Then in the admin Add Product page, use the "Original image file names / links" box and type one per line:
red-bag-1.jpg
red-bag-2.jpg
red-bag-3.jpg

You can also type the full path:
assets/products/red-bag-1.jpg

This method keeps the exact original file quality because the images are served as real files, not saved inside the Netlify database.
